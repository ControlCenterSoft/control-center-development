# Control Center 0.30.0 — квалификация исходного слоя

Статус документа: source qualification, не Public Stable.

Базовая стабильная версия: `0.29.0`.

## Объём 0.30.0

Квалифицируется read-only представление «Сайты / Узлы / Инвентарь»:

- дерево площадок и узлов;
- карточки узлов с ролями, возможностями, оборудованием и сетевой сводкой;
- явное отображение актуальности данных;
- явные границы наличия evidence для Desired State, Actual State и version skew;
- адаптивная компоновка, включая одну карточку узла в строке на узком экране;
- read-only provider/API boundary без побочных изменений инфраструктуры;
- JSON Schema контракта read-model.

## Безопасность и ограничения

- `unavailable`, `stale` и `expired` не должны отображаться как Healthy или как подтверждённое отсутствие объектов;
- ошибки authoritative-провайдера не раскрываются клиенту;
- API принимает только чтение и отклоняет mutation-методы;
- недоступные или неконсистентные данные обрабатываются fail-closed;
- опасные инфраструктурные операции в объём 0.30.0 не входят;
- новых SQL-миграций и новых сторонних runtime-зависимостей этот инкремент не добавляет.

## Release discipline

Этот документ не меняет release identity: `VERSION` остаётся `0.29.0` до отдельного шага release qualification. После успешной исходной квалификации для официального 0.30.0 отдельно проверяются release identity, build/package, clean install, поддерживаемый upgrade, security/recovery gates, документация и только затем выполняется официальный release/promotion.
